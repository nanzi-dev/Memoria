# Memoria 功能说明

本文承接 README 中的完整功能说明。README 只保留项目概览和入口，具体能力、行为边界与使用方式统一维护在这里。

## 角色模拟

- **结构化角色卡**：使用 JSON 定义角色的身份、背景、人格、语言风格、行为模式和交互规则。
- **多维度性格**：支持 MBTI、核心特质、价值观、恐惧与禁忌等字段。
- **动态语言风格**：根据角色设定生成符合人设的对话内容和表达方式。
- **角色卡管理后台**：Web 界面支持创建、编辑、导入、导出和数据库存储，资源按登录用户隔离。
- **玩家角色卡**：独立编辑玩家名称、头像、身份、外观、性格、背景和目标，并从下一条单聊或群聊消息开始参与 Prompt 与关系图谱。

## 对话系统

- **单角色对话**：支持会话创建、恢复、历史分页、SSE 流式回复和非流式回退。
- **多角色群聊**：每个群聊至少需要 2 个不重复 NPC；当前 API 最多接受 8 个参与者。
- **无自动开场白**：创建会话不生成开场白，`opening` 恒为 `null`，由玩家第一条消息触发对话。
- **讨论模式**：`max_responses` 接受 1-5，编排器按上下文动态决定回应人数，当前每轮最多生成 3 个角色回应。
- **智能发言策略**：固定使用混合策略，综合关键词、角色点名、关系、发言频率、均衡性和最近发言上下文。
- **角色间互动**：角色可以相互回应和讨论。
- **逻辑群聊线程**：`group_thread_id` 跨越物理 session 保持不变，结束后续聊仍可读取完整历史。
- **群聊脉冲**：世界时钟或事件可以触发 NPC 自主发言，每次脉冲最多提交 1 条角色消息。
- **未读聚合通知**：自主或事件脉冲原子创建线程级未读通知，客户端同步后可整线程标记已读。
- **对话幂等**：客户端 `request_id` 与持久化租约防止重复提交，已完成轮次会返回已存结果。

## 记忆系统

- **短期记忆**：保留最近对话历史，默认 8 轮，确保上下文连贯。
- **中期记忆**：自动生成会话摘要，支持跨会话持久化。
- **长期记忆**：自动提取重要事实，使用向量检索召回相关记忆。
- **记忆萃取引擎**：使用 AI 从对话中提取关键信息并评估重要性。
- **世界时间记忆曲线**：玩家事实、角色印象和群体经历会随世界时间衰减，并可由新证据强化。详见 [记忆曲线说明](MEMORY_CURVE.md)。
- **图谱修订隔离**：角色关系图谱更新或删除后，生成上下文时只过滤图谱变更前的旧关系事实；普通长期记忆、共同经历和世界事实继续保留。
- **多角色记忆**：个人记忆、角色间记忆和群体记忆分层管理；群聊结束时生成整场摘要并保存为群体记忆。

## 知识库与 RAG

- **多格式导入**：支持 UTF-8 TXT、Markdown、PDF、DOCX 和直接粘贴文本。
- **异步处理与恢复**：文档按 `queued -> processing -> ready/failed` 流转；服务重启后恢复排队中或被中断的任务。
- **精细绑定**：知识库可绑定为全局、指定角色或指定群聊线程，并可随时启用或禁用。
- **安全检索注入**：单聊和群聊按绑定范围检索知识块，知识只作为低优先级世界事实，文档中的指令不会被执行。
- **来源可追溯**：对话响应返回 `knowledge_sources`，管理页支持检索预览、失败原因展示和重试。

## 关系、情绪与剧情

- **好感度**：根据对话内容动态调整角色对玩家的好感度（-100 到 100）。
- **信任度**：追踪角色对玩家的信任程度，影响话题开放度。
- **情绪状态**：实时跟踪角色当前情绪，影响对话表现和反应。
- **关系图谱**：支持当前用户私有的角色间关系定义和网络查询；关系类型为可自定义文本。
- **关系增量兜底**：LLM 未返回增量时，根据文本和动作执行有界确定性调整。
- **剧情状态**：领域事件账本与剧情投影共同维护可查询的剧情进度。

## 事件与世界时钟

- **触发条件**：支持好感度、信任度、关键词、对话次数、时间、情绪和复合条件。
- **跨角色聚合**：阈值条件支持对指定角色执行 `any`、`all`、`count` 聚合。
- **事件效果**：支持状态修改、内容解锁、对话触发、记忆添加、情绪改变、玩家通知、关系修改、事件链和 NPC 主动对话。
- **检测与冷却**：自动检测触发条件，支持冷却时间、触发次数限制和互斥组。
- **时间事件**：支持 cron 式调度、事件模板库和跨会话事件上下文持久化。
- **用户隔离**：角色卡、事件定义和角色关系按登录用户隔离。
- **世界时钟**：每个用户拥有独立的 IANA 时区和 0/1/2/5/10 倍世界时间。
- **事件通知**：通知持久化到用户收件箱并支持已读状态。
- **事件模拟**：管理 API 可以在不执行、不写入副作用的情况下评估条件并预览计划结果。

## 语音

- **语音输入**：浏览器录音上传到认证 STT 接口，按会话语言转写，可配置自动发送。
- **语音播放**：单聊和群聊的角色消息支持 TTS、自动播放和本地文件缓存。
- **角色声音**：支持内置声音与自定义声音的授权、创建、状态查询和解绑；自定义声音不可用时回退内置声音。

## 沉浸感与输出安全

- **AI 身份检测**：`output_safety` 对完整回复和 SSE 增量做风险模式过滤，命中后替换为安全兜底句。
- **角色一致性**：严格约束模型输出，保持角色人设。
- **三层容错**：JSON 解析、修复重试、文本兜底。

## 模型支持

- **OpenAI 兼容接口**：支持 DeepSeek、Kimi、Qwen、OpenAI 等兼容服务。
- **主辅模型分离**：主对话使用高质量模型，记忆萃取等轻量任务可使用独立模型。
- **结构化输出**：支持 JSON 强制输出的模型可以获得更稳定的解析结果。

## Web 前端

- **登录与用户资料**：支持注册、登录、资料编辑和头像设置。
- **安全登录态**：浏览器使用 `memoria-token` HttpOnly Cookie 和 `memoria-csrf` 可读 Cookie，写请求自动携带 `X-CSRF-Token`。
- **安全头像下载**：服务端校验 URL 并固定已验证 IP，拒绝私网、保留地址和 Fake-IP 直连。
- **角色卡编辑器**：分步编辑身份、性格、语言风格、背景和交互规则。
- **会话体验**：支持单角色对话、会话恢复、多角色群聊、录音转写和角色语音播放。
- **流式与群聊同步**：SSE 增量展示回复，群聊使用逻辑线程合并历史并同步未读状态。
- **管理工作台**：事件与知识库页面支持汇总、搜索、筛选、排序、详情查看和编辑。
- **用户设置**：账户、世界时间和语音设置分区管理。
